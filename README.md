# splatoon-2-schinese-patch / Splatoon2 中文化项目
## 基于以下文本翻译
- Splatoon 2 (Ver. 5.5.0) 日语文本
- Splatoon 3 (Ver. 1.1.2) 简体中文UI/可共用专有名词/物品/小部分固定短句文本
- 剩余文本是基于 Deepseek-v4-flash 进行的 AI 翻译，不一定准确且不一定贴合官方翻译口吻
